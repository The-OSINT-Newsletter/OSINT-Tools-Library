### What does EarthPoint Convert do?

EarthPoint Convert converts geographic coordinates between different coordinate systems and formats, helping make location information easier to analyse, visualise, and compare across different sources.&#x20;

It’s designed to help users translate location data into formats compatible with mapping platforms such as Google Earth, GIS software, and other geospatial tools.

**The lowdown:** It’s particularly useful when a source provides location information in an unfamiliar format or when coordinates need to be prepared for mapping.

### Use in Reporting

EarthPoint Convert can support reporting by:

* Standardising coordinates before including them in reports.
* Converting location data into formats understood by mapping platforms.
* Helping analysts verify and display geographic evidence.
* Supporting geolocation investigations where coordinates are provided from multiple sources.

**Note:** When used in reporting, analysts should record the original coordinate format and the conversion method used to maintain transparency and reproducibility.&#x20;

| **Capabilities**                                         | **Limitations**                                                              |
| -------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Converts geographic coordinates between common formats.  | Doesn’t provide imagery, satellite analysis or location intelligence itself. |
| Helps prepare location data for mapping platforms.       | Accuracy depends on the quality of the input coordinates.                    |
| Supports quick coordinate validation and formatting.     | Limited analytical features compared with dedicated GIS software.            |
| Useful for geolocation investigations.                   | Online processing may not be suitable for sensitive operational data.        |

### Summary

EarthPoint Convert is a simple but useful geospatial support tool that best fits during the data preparation and analysis stages of the OSINT workflow where investigators need to clean, standardise, or convert geographic information before mapping or reporting.

### Ethical Considerations

* Ensure location data is collected and used lawfully.
* Avoid processing sensitive personal location information without appropriate authority.
* Maintain records of original data sources and conversion methods.
* Do not assume converted coordinates are accurate without verification.
* Consider operational security when handling location-based intelligence.
