### What does Sowsearch do?

Sowsearch simplifies Facebook’s cluttered native search by generating structured Facebook search queries automatically. Instead of manually testing search terms and filters, users can quickly create targeted searches that point directly toward potentially relevant public content.&#x20;

**The lowdown:** It simplifies the process of finding public Facebook content that would otherwise be difficult to locate through Facebook’s standard search interface.&#x20;

### Use in Reporting

Sowsearch can support:

* Social media intelligence reports.
* Public sentiment analysis.
* Protest or event investigations.
* Narrative tracking.
* Timeline reconstruction.
* Community mapping.
* Open-source attribution investigations.

As a real world example, analysts use tools like Sowsearch in event and protest monitoring to quickly surface Facebook posts mentioning a location or event (for example a demonstration in a city). They can then pivot to the original posts to build timelines of activity, identify key organisers, or track information spread across groups and pages.&#x20;

**Note:** Because social media content can change rapidly, investigators should preserve evidence appropriately using screenshots, archiving tools, or exports where lawful and permitted.

| **Capabilities**                           | **Limitations**                                          |
| ------------------------------------------ | -------------------------------------------------------- |
| Enhanced Facebook searching.               | Restricted to publicly accessible content.               |
| Discovery of public posts and discussions. | Facebook privacy settings heavily affect visibility.     |
| Group and event identification.            | Search results can change frequently.                    |
| Faster timeline reconstruction.            | Deleted content cannot reliably be recovered.            |
| Keyword and date-based searching.          | Requires a Facebook account for many results.            |
| Social network and community discovery.    | Dependent on Facebook’s own indexing and search systems. |

### Summary

Sowsearch primarily sits within the collection, discovery, and analysis stages of the OSINT workflow, helping users gather publicly available Facebook content, discover relevant people, groups, events, and discussions, and analyse social interactions, timelines, and narratives connected to an investigation.
