### What does Corvus do?

Corvus combines case management, selected online collectors, evidence imports, relationship graphs, timelines and reporting in a local web interface. Findings can be reviewed with their source references before being incorporated into a report.

### How to Use:

Follow the [installation guide](https://github.com/sn0ba11/corvus/blob/main/docs/DEPLOYMENT.md). Start with a synthetic case to familiarise yourself with the interface. Online collectors can be disabled for offline review.

### Cost

## Data Processing

### Account Required:

* [x] No central account required.

### Cookies:

Browser profiles can retain authentication cookies. Case data, exports and retained captures are stored locally. Selected online actions send queries or URLs to external services. See the [privacy documentation](https://github.com/sn0ba11/corvus/blob/main/docs/PRIVACY.md).

### Use in Reporting

Review provenance and organise findings before exporting case evidence. Findings should be independently verified before drawing conclusions.

| **Capabilities** | **Limitations** |
| --- | --- |
| Local case and evidence management | Local installation and configuration required |
| Graphs, timelines and report generation | External services can impose rate limits or change availability |
| Offline evidence review | Online collectors require network access |
| Windows installer and Linux deployment | Public pre-release; native macOS installation testing is deferred |

### Summary

Corvus is a local investigation workbench for collecting, organising and reviewing evidence rather than a substitute for analyst judgement.
