### What does Babylon do?

Babylon is a dictionary and translation platform that allows users to search words or terms in different languages. The wider Babylon software provides one-click translation, text and document translation, dictionaries, encyclopedias, Wikipedia integration, pronunciation and other language tools.

For OSINT purposes, it’s potentially useful when you encounter foreign-language names, usernames, documents, websites, social-media posts, company information or terminology.

**The lowdown:** It’s a language and translation tool that provides dictionaries from multiple sources.

### How to Use:

**1. Download the Babylon demo to your desktop to efficiently test out the tool. (The free test on the web version only allows you to search English words/phrases).**&#x20;

**2. Enter the text into Babylon's dictionary/translation interface, allow it to detect the language or manually select the appropriate language, then review the translation. You can also upload documents to translate.**

No for the online dictionary/basic use. An account/licence may be required for some software and premium features.

### Cookies:&#x20;

Babylon uses Sourcebuster.js analytics/marketing-attribution cookies, including sbjs\_first, sbjs\_first\_add, sbjs\_current\_add, sbjs\_session and sbjs\_udata. These record information such as the visitor's acquisition source, referring URL, entry/current page, session activity and browser/user-agent information.&#x20;

The site also uses wp-wpml\_current\_language to store the selected language.

### Use in Reporting

Babylon can be used to:

* Translate foreign-language words, phrases and documents encountered during OSINT research.
* Identify the meaning and context of foreign-language terminology, names and expressions.
* Support investigations involving foreign-language websites, social-media content and documents.
* Generate translated terminology that can be used to conduct further searches in the original language.
* Corroborate translations obtained from other translation and dictionary services.
* Document the original-language term, translation, language and source used during an investigation.
* Support analysis where language barriers would otherwise limit access to relevant information.

| **Capabilities**                                                     | **Limitations**                                                                        |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Provides multilingual dictionary and translation functionality.      | Machine translation can introduce errors or lose cultural/contextual meaning.          |
| Can translate words, phrases and longer passages.                    | A translation should not automatically be treated as an authoritative interpretation.  |
| Supports document translation in several common formats.             | Advanced functionality requires a paid licence, particularly on the web version.       |
| Provides dictionaries from multiple sources and premium publishers.  | Language coverage and dictionary availability vary by product/licence.                 |
| Can provide useful terminology for subsequent searches.              | Names, slang, dialects, irony and specialist terminology can be mistranslated.         |

### Summary

Babylon can assist investigators in understanding foreign-language websites, documents, terminology and other OSINT material and best fits in the translation and enrichment stages of the OSINT workflow. An investigator can use it after collecting foreign-language material to understand the content and identify terminology for subsequent searches.

### Ethical Considerations

* Do not treat machine translation as definitive where an interpretation could materially affect an investigation.
* Verify important translations with an independent source or qualified human translator.
* Take particular care with names, slang, dialects, sarcasm, cultural references and specialist terminology.
* Consider data-protection requirements when translating material containing personal information.
* Record the translation tool, date and language used where a translated passage is relied upon in reporting.
* Avoid presenting a machine-generated translation as a direct quotation from the original source.
