### What does Xquik do?

Xquik gives investigators and analysts a documented API and MCP path for X (Twitter) data workflows. It covers public-data collection tasks such as tweet search, account lookup, follower exports, media downloads, monitoring, webhooks, and structured agent access.

The tool is most useful when an investigation needs repeatable X data collection instead of one-off manual browsing.

### How to Use:

1. Open the public documentation at [https://docs.xquik.com/](https://docs.xquik.com/).
2. Create an API key in Xquik.
3. Choose either the REST API reference or MCP setup guide for the workflow.
4. Collect only data that is relevant to the investigation and preserve source context for later verification.

### Use in Reporting

Xquik is useful for:

* Finding public X posts by keyword or account.
* Reviewing public account data and timelines.
* Exporting follower or following data for analysis.
* Downloading relevant public media.
* Monitoring accounts or topics and receiving webhook events.
* Connecting agent workflows through MCP.

Analysts should verify results against the original public source, preserve timestamps and URLs, and avoid collecting unrelated personal data.

| **Capabilities**                                      | **Limitations**                                                   |
| ----------------------------------------------------- | ----------------------------------------------------------------- |
| Tweet search and public account lookup.               | Requires an Xquik account and API key.                            |
| Follower exports, media download, monitoring, webhooks. | Coverage and access depend on current documented Xquik API scope. |
| REST API and MCP setup for repeatable workflows.      | Findings still require manual context checks before publication.  |

### Summary

Xquik fits the collection and monitoring stages of an OSINT workflow when analysts need structured X data, repeatable exports, or agent-readable API access. It should be paired with source verification and careful context review.

### Ownership

Xquik is the owner and operator of the platform.

### Ethical Considerations

* Collect only data that is necessary for the investigation.
* Respect privacy, platform rules, and applicable law.
* Preserve source URLs, timestamps, and context.
* Avoid publishing personal data that could create unnecessary harm.
* Treat automated outputs as leads that require human verification.
