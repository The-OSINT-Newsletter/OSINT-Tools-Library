### What does Internect.info do?

Internect.info functions as a search tool for Bluesky. It allows users to locate user handles, confirm account existence, and explore publicly available profile data across the decentralised network.&#x20;

**The lowdown:** It’s a lightweight OSINT search tool for Bluesky handles, useful for quickly locating and verifying social media presence.
