### What does Bulletpicker do?

Bulletpicker is a niche reference database focused on ammunition identification. It provides visual and technical details about cartridges, helping analysts determine what type of bullet or round appears in images or recovered material. It’s especially helpful when you’re trying to match a round to a weapon system or verify claims in conflict reporting.&#x20;

**The lowdown:** It’s essentially a specialist catalogue for bullets and cartridges.

### Use in Reporting

Bulletpicker is useful for:&#x20;

* Conflict OSINT investigations.
* Weapon identification in imagery/video.
* Supporting forensic or journalistic analysis.
* Verifying calibre claims in reports or footage.

The tool is best understood as a reference/checking tool in OSINT workflows, and while it's widely known in practitioner communities, it's rarely formally cited as a standalone source in published investigations.&#x20;

| **Capabilities**                                               | **Limitations**                                                          |
| -------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Large reference database of ammunition types and cartridges.   | No advanced search or filtering tools.                                   |
| Visual identification support (photos and diagrams).           | Not always updated with the latest ammunition developments.              |
| Technical specs like calibre, dimensions, and case type.       | Limited context beyond basic cartridge identification.                   |
| Helps match ammunition to known weapon systems.                | Cannot reliably identify weapons from partial or unclear imagery alone.  |
| Useful for OSINT verification in conflict imagery and footage. | Not an official/institutional forensic database.                         |

### Summary

Bulletpicker is a lightweight but useful OSINT reference for ammunition identification, best used as a supporting tool alongside imagery analysis and other weapons databases.

### Ownership

Owned and operated by Ted Carlson, a technical resource developer, former explosive ordnance disposal technician and retired project manager for the Department of Defense.

### Ethical Considerations

* The tool should be used strictly for analysis, journalism, and research.
* Be mindful of the risk of misuse in weapon profiling or sensitive investigations.
* Always avoid using identification data to facilitate harm or targeting.
* Make sure to cross-check findings with multiple sources before reporting.
