### What does ZIPZAX Image Metadata Viewer do?

ZIPZAX Image Metadata Viewer reads EXIF, IPTC and XMP metadata where supported, shows filename, byte size and dimensions, enables grouped tags you can browse and search, plus there is an option to hide location values in the copied or exported (.txt) report.

**The lowdown:** It can help identify information that may otherwise be overlooked when viewing an image normally.

### Use in Reporting

ZIPZAX Image Metadata Viewer can be useful for:

* Examining available EXIF, IPTC and XMP metadata in an image to identify potentially useful provenance information.
* Recording camera make, camera model, capture-date fields and image dimensions when those values are present and supported.
* Identifying embedded GPS coordinates that may provide a lead for geolocation and comparison with visible landmarks.
* Comparing metadata across related images to identify similarities or inconsistencies in timestamps, device information or file properties.
* Supporting investigations involving image provenance, geolocation, chronology, source assessment or the verification of publicly circulated photographs.
* Producing a text report of displayed metadata for case notes, comparison and documentation.
* Supporting further verification by identifying metadata fields that can be checked against original files, other images, public sources or independent geolocation evidence.

Important Note: The viewer is a metadata-inspection aid, not an image-authentication or forensic verification service. Its output should be treated as an analytical lead rather than conclusive proof of when, where or by whom an image was created

| **Capabilities**                                                        | **Limitations**                                                                                         |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Reads EXIF, IPTC and XMP metadata where supported.                      | Coverage depends on format and embedded tags.                                                           |

### Summary

ZIPZAX Image Metadata Viewer is a straightforward browser-based utility for examining metadata embedded in image files and is most useful for image verification and metadata checks early in the workflow.

However, the tool should not be treated as an image-authentication system. Missing metadata does not prove that an image is false or anonymous, and present metadata does not guarantee authenticity.

### Ethical Considerations

* Be mindful that metadata can expose a person's location and device.
* Only inspect images you are entitled to analyse.
* Remove location data before sharing personal photos.
* Corroborate significant findings before attributing an image to a person, place or time.
