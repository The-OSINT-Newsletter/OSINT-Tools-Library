### What does the Tool Do?

The checker implements the length, character-set and check-character rules of GB 32100-2015. It displays the code fields and limited explanations of the prefixes.

It does not query a company registry. A passing code is internally consistent, but it may have been copied from another entity or constructed to pass the calculation. It does not establish company existence, current status or correct transcription.

### How to Use:

1. Obtain the complete 18-character code from a licence, PDF or other source.
2. Enter the code in the checker and run the check.
3. If it fails, compare it with the source document. Do not change characters simply to make it pass.
4. Continue with a separate registry search using the exact code and Chinese legal name where appropriate.
5. Keep the document source and date with any reported result.

### Cookies:

The arithmetic runs in the browser. No cookies for the tool's domain were observed in the 19 September 2026 browser check; this is a dated observation, not a guarantee about all browser settings or future versions.

The page places the input in the URL fragment for sharing. Anyone given that link can see the entered code. The hosted site has usage measurement; browser-local arithmetic does not imply anonymous site access. See the [site privacy notice](https://currawongweb.com/privacy/).

### Use in Reporting

The tool can flag format and check-character discrepancies in company identifiers obtained from public documents. Report the technical result separately from any conclusion about the company.

| **Capabilities** | **Limitations** |
| --- | --- |
| Checks length, permitted characters and check character. | Does not verify the code against a live registry. |
| Explains selected code fields. | Does not validate every administrative code or a factory's location. |
| Helps identify input errors before further research. | A passing result does not establish identity, trading status, account ownership or export permission. |

### Summary

This is a supporting identifier check, useful before company-record research. Its result cannot replace the original document, a dated registry record or transaction-specific evidence.
