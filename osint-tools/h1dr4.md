# H1DR4

| Tool | Quick overview |
| --- | --- |
| URL | [Public incident map](https://h1dr4.dev/map) |
| What it does | Maps reported incidents and provides an index of public case files and official records. |
| Cost and access | Public browsing is free and requires no account. Private workspace features require sign-in. Some features are paid. |
| Operator | H1DR4. This entry was submitted by the project author. |

### How to use

1. Open the [map](https://h1dr4.dev/map) to explore public reports by location.
2. Open the [public case index](https://h1dr4.dev/cases?category=community) to find a dossier. Review dated events, source links and related evidence.
3. For an example of a source-linked timeline, see the [Learjet N722BD dossier](https://h1dr4.dev/cases/read?type=dossier&id=53238857-9960-45c7-a778-e6f1f585f92b).

### Use in reporting

The incident layer can surface leads about a place. The case files let a reporter inspect the chronology and trace claims back to sources. Coverage depends on the records available for the location and period. Check the underlying record before citing an incident, and corroborate community submissions independently.
