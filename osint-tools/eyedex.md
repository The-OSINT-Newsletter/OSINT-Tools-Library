### What does Eyedex do?

Eyedex searches a large index of publicly accessible files and directories that are available on web servers. Rather than searching web pages, it focuses on the files themselves, allowing users to search billions of files exposed through web-accessible directory indexes and identify documents, media files, archives, software, datasets, and other resources that may not be indexed by traditional search engines.&#x20;

**The lowdown:** It can be a valuable niche tool for discovering forgotten, misconfigured, or publicly exposed content.

### Use in Reporting

Eyedex can support reporting by helping investigators:

* Locate publicly available documents.
* Verify leaked or circulated files.
* Find historical versions of reports.
* Discover technical documentation.
* Identify exposed resources.
* Support investigative leads.
* Locate supporting evidence in public directories.

Whilst Eyedex is rarely cited, it is potentially valuable for uncovering documents that become evidence elsewhere.

| **Capabilities**                                                          | **Limitations**                                                        |
| ------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Searches large numbers of publicly accessible directory listings.         | Only indexes directories and files that are publicly accessible.       |
| Located documents, archives, media files, and datasets.                   | Coverage is not comprehensive across the entire internet.              |
| Supports file-type specific searching.                                    | Search results may contain outdated, duplicate, or irrelevant content. |
| Can uncover content not easily found through traditional search engines.  | Open directory content can disappear without notice.                   |
| Useful for document discovery and technical OSINT investigations.         | Findings often require additional verification and context.            |

### Summary

Eyedex is a niche but powerful tool for discovering files and resources stored in publicly accessible web directories, best used during the collection, discovery, and enrichment stages of the OSINT workflow.
