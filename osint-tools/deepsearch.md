# DeepSearch

| DeepSearch | Quick overview |
| --- | --- |
| URL | https://deepsearch.tools/ |
| What it does | Helps users search by name and compare possible people matches. |
| How to use it | Enter a name, optionally refine by city or company, and review the candidate list before selecting a possible match. |
| Cost | Candidate-list preview is free; full reports are paid. |
| Account required | No login is needed for the free candidate-list preview. |
| Use in research | An initial lead for identifying possible matches, subject to independent verification. |

## Limitations and ethical considerations

A shared name does not establish identity. Results may be incomplete, outdated, or associated with a different person. Corroborate important information against original sources, respect privacy, and use the tool for legitimate purposes.
