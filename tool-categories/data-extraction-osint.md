# Data Extraction OSINT

Data Extraction OSINT focuses on collecting and structuring publicly available information from websites, documents, and online platforms. These tools help investigators gather large volumes of data efficiently, transform unstructured content into usable formats, and analyse patterns or insights across multiple sources.
